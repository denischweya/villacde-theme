# Villa CDE Theme

A standalone WordPress FSE theme for Villa CDE (villacdenaivasha.co.ke),
forked from Twenty Twenty-Five and rebranded. No dependency on Twenty
Twenty-Five being installed — this theme is self-contained.

Pairs with the [villacde-core](https://github.com/denischweya/villacde-core)
plugin for the site's custom interactive blocks.
